# 词海无涯，回头是岸（单文件版）

> 名字取自「学海无涯，回头是岸」——背着背着，回头是岸。`index.html` 双击即用的四级词汇背诵网站：默写检测 + 词义检测 + 生词本，数据自动保存在浏览器里。

## 快速开始

直接双击 **`index.html`**（用 Chrome / Edge 打开即可），不需要装任何东西、不需要联网。

打开后先选词书：**四级词汇**（已上线，4424 词条）、六级词汇、高考词汇（后两本显示为灰色，点一下会提示「尚未上线，敬请期待」）。选完四级进入主界面。

## 三个功能

### 1. 默写检测
- 给出**精简后的中文释义**，输入英文单词。
- **首字母默认给出**（如 `s _________`）。
- **提示**：点一次再多给一个字母（如 `s t ________`），每个词**只能用一次**，用完按钮变灰。
- **不会**：直接判错、显示整张单词卡片、放进生词本，然后跳到下一题。
- **答错**：显示你输入的内容 + 正确答案，并放进生词本。
- 判定规则：忽略大小写、忽略首尾空格；词内空格必须写；连字符写不写都算对。
- 答对 **0.6 秒自动进入下一题**。答错/不会/跳过弹出答案后，**按回车或点「下一题」都能继续**，全程可只用键盘。

### 2. 词义检测
- 给出英文单词，从 5 个选项里勾选。
- 选项按**语义拆分**：同一词的不同意思（如 `key` 的「钥匙」「关键」「解答」「调子」）是**不同选项**；
  同义/近义（如「关键」和「要害」）**合并在同一个选项里**。
- 有多个正确义项时，**必须全部选对**才算对；漏选 / 错选都会展示正确答案。
- **答对后 0.7 秒自动进入下一题**（和默写一致）；答错会停在本题看正确答案，手动点「下一题」。
- **不会**：直接判错、进生词本，并自动跳到下一题。

### 3. 生词本
- 答错、不会、**用过提示**的单词都会进来。
- 单词旁显示错误次数（红色 `×N`）。
- 答对一次即移出生词本；也可以手动移除或一键清空。

## 键盘操作

- 默写：输入框里按回车 = 提交；答完（含答错/不会/跳过）后按回车 = 下一题。
- 词义：回车 = 提交；答对后自动跳题，答错后回车 = 下一题。

## 提交细节

- 默写：输入为空不会判错，会提示先输入（想标记不会请点「不会」）。
- 词义：一个选项都没勾也不会判错，同样会提示。
- 这样连按回车不会误把下一题判错。

## 出题规则

- 每场 **25 题**，分两部分：
  - **最多 5 题来自生词本**（答错 / 不会 / 给过提示的词），错误次数多的优先；
  - **其余全部是没考过的新词**。
- 生词本不足 5 个时，新词数量自动补足（例如生词本只有 3 个 → 3 题复习 + 22 题新词）。
- **已经考过且答对的词不会再出现**（它们已移出生词本，视为掌握）。
- 只有新词全部考完（约 176 场之后）才会回收旧词，按「最久没考」的顺序。
- 同一场 25 题**不重复**。

## 数据保存

- **自动保存**：每答一题立刻写入浏览器 `localStorage`，关掉网页再打开数据还在。
- **导出备份**：首页底部「导出备份」→ 下载 `cet4-vocab-backup-YYYYMMDD.json`。
- **导入备份**：首页底部「导入备份」→ 选择之前导出的文件。
- ⚠️ 清理浏览器缓存/站点数据、换浏览器、无痕模式会丢数据，记得偶尔导出一份。

## 词义拆分是怎么做的

原 PDF 的释义是一整串（如 `n.钥匙,关键,解答,(打字机等的)键,调子,...,要害`），直接拿去当选项会一个选项塞进七八个意思；而单纯按逗号拆，又会把「好奇的 / 有求知欲的」这种同义说法拆成两个选项。构建时做了四层处理（`tools/split_senses.py`）：

1. **拆**：按逗号/顿号/分号切成单条义项；括号内的内容整体保留（`(开钟表、发条的) 栓` 不会被切成两半）。
2. **归一**：比较前先去掉「的/地/了」后缀、省略号、词性标记和空格，并剥掉「使/被/把/给」这类前缀。
3. **并**（关键一步）：满足任一条就并成同一个意思——
   - 归一后完全相同；
   - 命中同义词表（`SYN_GROUPS`，约 280 组，覆盖「好奇/有求知欲」「怀疑/嫌疑/疑心」「攀登/爬」等）；
   - 一个是另一个的包含（长度差 ≤ 4）；单字根只认「以它开头的短词」（`光 → 日光`，但 `键` 不会吃掉 `关键`）；
   - 字面重合 ≥ 60%。
4. **概念归组**：合并后的每条义项生成一个概念簇 id，同一簇只作一个选项；`CONCEPTS` 表用于手工兜底（字面差太远但确实同义、或需要强制分开的极端情况）。

**校验工具**：`python tools/check_clusters.py` 会扫描全库，把「同一个词里两条义项很像」的配对按相似度降序列出来，方便继续补同义词表。改完这一轮后，可疑配对从 14,463 组降到约 6,700 组，剩下的多数是「A 包含 B」但确实不同的义项（如「年 / 年纪」）。

`vocab_senses.json` 是这一步的中间产物，方便你检查/手工修正某些词的分组。

## 项目结构

```
cet4-vocab/
├── index.html            ← 最终产物，双击即用（词库已内嵌，约 1.5 MB）
├── requirements.md       ← 需求文档 v3.0
├── README.md
├── vocab_clean.json      ← 清洗后的词库（4,424 条，字段 word/short/senses）
├── vocab_senses.json     ← 义项拆分/合并结果（含概念簇 id）
├── docs/                 ← 界面截图
├── src/
│   └── app.html          ← 应用源码模板
└── tools/
    ├── extract_vocab.py  ← 从原始 PDF 生成 vocab_clean.json
    ├── split_senses.py   ← 义项拆分与同义合并 → vocab_senses.json
    ├── check_clusters.py ← 校验：找出漏合并的相似义项
    ├── inject_synonyms.py← 把扩展同义词表注入 split_senses.py
    ├── build.py          ← 内嵌词库，生成 index.html
    ├── cdp.js            ← 无依赖的浏览器自动化小工具
    └── test_final.js     ← 端到端验收测试
```

## 修改与重新构建

```bash
python tools/build.py            # 改完 src/app.html 或词库后重新打包
python tools/split_senses.py     # 改了义项规则/同义词后重新拆分
python tools/extract_vocab.py    # 从 PDF 重新生成词库（需 pip install pypdfium2）
```

改同义词只需编辑 `tools/split_senses.py` 里的 `SYN_GROUPS` 和 `CONCEPTS` 两张表。
